배관 내경 (mm) = √( Q × 1000 / (60 × π/4 × v) × (101.325 / (P + 101.325)) )

유량계수 계산
💧 노즐 구경 → 유량 계산 (물 기준, 직선 패턴 0°)
Q (L/min) = Cd × π/4 × d² × √(2 × g × P × 10⁴) / 1000
= Cd × 14.96 × d² × √P (단순 근사식, Cd=1 기준)
💧 노즐 구경 + 유량 → 압력 계산
P (bar) = (Q / (Cd × 14.96 × d²))²
💧 압력 + 유량 → 오리피스 구경 계산
d (mm) = √( Q / (Cd × 14.96 × √P) )
📐 유량계수(Cd) 계산
Cd = Q / (14.96 × d² × √P)

기호명칭설명관련 계산
A이론 분사폭분사 거리(H)와 분사각도(θ)만으로 계산한 분사 폭A = 2 × H × tan(θ/2)
B실제 분사폭A에 조립각도(편각) 보정을 적용한 실제 분사 폭B = A × (1 − 조립각도 비율)
C중첩 폭인접 두 노즐의 분사 영역이 겹치는 폭피치(F) < 분사폭(B) 일 때 발생
E전체 커버범위전체 노즐이 커버하는 가로 범위E = F × (N−1) + B
F노즐 설계 피치인접 노즐 사이의 간격사용자 입력값
H분사 거리(비거리)노즐 ~ 피도물 표면까지의 거리사용자 입력값
N노즐 수량피도물 폭을 커버하기 위한 노즐 개수N = ⌈피도물폭 W / F⌉

노즐에서 분출되는 유체가 목표 표면에 가하는 이론상 충격력을 계산합니다.
💥 이론상 분사 충격력 계산식
충격력 (kgf) = 0.024 × Q (L/min) × √P (bar)
☞ 노즐에서 분출되는 유체가 목표 표면에 받는 힘을 말합니다.
☞ 이 값은 분사 각도와 패턴에 따라 달라질 수 있습니다.
☞ 해당 계산식은 물 기준 자료이며, 현장 조건에 따라 다를 수 있습니다.

평행축 정리
⬛ 사각형 단면 — 단면2차모멘트(I) · 단면계수(Z)
I = b × h³ / 12  [cm⁴] Z = b × h² / 6  [cm³] Ix = h × b³ / 12 (약축)  [cm⁴] Zx = h × b² / 6 (약축)  [cm³]
⭕ 원형 · 중공원형 단면 — I · Ip · Z · Zp
I = π(D₂⁴ − D₁⁴) / 64  [cm⁴] Ip = π(D₂⁴ − D₁⁴) / 32  [cm⁴] ← 극단면2차모멘트 Z = I / (D₂/2)  [cm³] Zp = Ip / (D₂/2)  [cm³] ← 극단면계수 ※ 중실 원형: D₁ = 0 으로 입력
☞ 중실 원형은 내경 D₁ = 0으로 입력하세요.
☞ Ip (극단면2차모멘트)는 비틀림 계산에 사용됩니다.
↔ 평행축 정리 (Parallel Axis Theorem)
Ix' = Ix + A × y²  [cm⁴] Iy' = Iy + A × x²  [cm⁴] Ix : 도심축(X축)에 대한 단면2차모멘트 Iy : 도심축(Y축)에 대한 단면2차모멘트 A : 단면적 [cm²] x : Y축 → Y'축 거리 [cm] y : X축 → X'축 거리 [cm]
